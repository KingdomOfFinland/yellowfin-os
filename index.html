so, what is YellowfinOS?

A small operating system project with a big appetite for learning.

YellowfinOS 0.2 is a from-scratch operating system project for the i686 architecture. It brings together boot code, the Corn Kernel, storage and device support, the Fish shell, and an experimental graphical desktop. This release adds a Command Prompt window to the desktop, where shell commands can run inside a window. The goal is to learn how the pieces fit together by building them — and improving them one step at a time.

under the surface

Meet some of the parts that make the fish swim.

⚙️

Corn Kernel

The custom C-based kernel at the heart of YellowfinOS, targeting 32-bit i686 systems.

🖥️

graphical desktop

An evolving framebuffer-based desktop with windows, a mouse interface, and a glassy visual direction.

⌨️

Fish shell

The built-in fsh command-line environment, with system tools and a fish-themed prompt.

⌨️

Command Prompt

New in 0.2: a desktop command window that runs Fish shell commands, with its own prompt and output.

💾

FTFS storage

A custom filesystem experiment, alongside ATA disk support and virtual-disk testing.

🧩

device support

Work in progress across timers, RTC, keyboard, mouse, graphics, and experimental networking.

🧪

built to experiment

New ideas, debugging, fixes, and features. The project grows as the system grows.
