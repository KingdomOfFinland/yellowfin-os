⚠ experimental software
YellowfinOS is early-stage software. Expect bugs, missing features, lag, and incomplete drivers. It is intended to run in QEMU, VirtualBox, VMware, or the v86 emulator. Real-hardware support is not currently available.

so, what is YellowfinOS?

A from-scratch operating system project — not a Linux, Windows, or BSD-based distribution.

YellowfinOS is a learning and experimentation project focused on building the pieces of an operating system: boot code, a kernel, system services, storage support, and a graphical environment. It is very much a work in progress, and that's part of the point.

desktop environment
